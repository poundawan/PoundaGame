# PoundaGame — Les Lanterniers (titre provisoire)

Jeu de société hybride **JdR × plateau** en univers fantasy, accompagné d'une application
qui sert de **Maître du Jeu autonome** (ou d'assistant pour un MJ incarné).

- 1 à 6 joueurs · dès 10 ans · ~1 h par scénario
- Plateau modulaire en tuiles, cartes, figurines, dés polyédriques (d4 → d20)
